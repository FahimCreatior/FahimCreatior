## 🏗️ FEATURED PROJECTS

### 🎬 1. FAHEEMFLIX — Streaming Platform

<a href="https://faheemflix.top">
<img src="https://img.shields.io/badge/VISIT-FAHEEMFLIX-E50914?style=for-the-badge&logo=netflix&logoColor=white"/>
</a>

**FAHEEMFLIX** is a streaming-focused web application built around delivering a modern entertainment discovery and playback experience.

The project explores the architecture of a streaming platform, including frontend development, backend services, external APIs, media delivery, and mobile application development.

**Key technologies and features:**

- React-based web application.
- TMDB API integration for movie and television metadata.
- Movie discovery, search, details, and recommendations.
- Actor information and filmography integration.
- YouTube trailer integration.
- Backend API development.
- User authentication and profile management.
- MongoDB Atlas integration.
- Cloudflare R2 media storage exploration.
- Video upload and processing architecture.
- HLS streaming and adaptive bitrate playback development.
- Native Android application development using Kotlin and Jetpack Compose.
- PWA and mobile-friendly interface development.

**Technology stack:**

`React` `JavaScript` `Node.js` `Express` `MongoDB` `TMDB API` `Cloudflare R2` `Railway` `Netlify` `Kotlin` `Jetpack Compose` `Media3`

🌐 **Live:** https://faheemflix.top
